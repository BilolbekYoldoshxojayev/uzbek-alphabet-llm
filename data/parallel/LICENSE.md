# Data license

The files in this folder are adapted from FLORES-200 and Belebele (`facebook/belebele`), both under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). These adapted versions are shared under the same license.

**Changes made:** the Uzbek text is converted into other spellings: apostrophe variants, the 2026 alphabet, Cyrillic, partial conversions, back-converted text and mixed apostrophes. The text is machine-converted and contains errors; see `handcheck_sample.tsv` and `results/analysis/`.

Please cite the original datasets and this repository.
